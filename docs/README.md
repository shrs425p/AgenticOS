# Maharashtra High School, Chiplun Web Portal

Official website for Maharashtra High School, Chiplun.

## Directory Structure
- `index.html`: The main landing page.
- `pages/`: Contains all other subpages (About, Academics, Admissions, etc.).
- `assets/css/`: Stylesheets for the project.
- `assets/js/`: JavaScript scripts.
- `assets/images/`: Images used across the site.
- `assets/documents/`: PDF documents like academic calendars, syllabus, etc.

## Responsive Design
The project is designed to be mobile and tablet friendly.
